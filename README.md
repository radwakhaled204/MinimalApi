# Minimal API for Product Management
## Description
This project is a simple Minimal API built with ASP.NET Core. The goal of this project was to practice and learn about Minimal APIs and how they differ from traditional MVC-based APIs.

I created this API to manage products, with operations like adding, retrieving, updating, and deleting products. The project uses an InMemory Database with Entity Framework Core for storing product data, making it perfect for experimentation and learning.

This project helped me understand how to build lightweight APIs using minimal code and configurations, which is the core idea behind Minimal APIs in ASP.NET Core.

## Features
Add a new product

Get all products

Get a product by ID

Update an existing product

Delete a product
